# Data Analysis Projects

A collection of exploratory data analysis (EDA) projects built with Python, Pandas and NumPy. Each project follows a structured set of tasks, from basic inspection to written analytical findings.

## Objectives

- Build practical skills in data cleaning, filtering, aggregation and statistics.
- Practise turning raw data into clear, evidence-based conclusions.
- Document every step so the work can be reproduced and reviewed.

## Projects

| # | Project | Main Question | Key Skills | Status |
|---|---------|---------------|------------|--------|
| 1 | [Spotify Tracks](01-spotify-tracks/) | Which audio features and genres relate to popularity? | Filtering, `groupby`, descriptive statistics | In progress |
| 2 | [Netflix Titles](02-netflix-titles/) | How does the catalogue vary by type, period, country and rating? | Dates, string cleaning, missing data | Not started |
| 3 | [Formula 1](03-formula-1/) | How do drivers and constructors perform across seasons? | Aggregation, derived metrics, `np.select` | Not started |
| 4 | [International Football](04-international-football/) | How do results, goals and home advantage vary over time? | Datetime analysis, outcome classification | Not started |
| 5 | [World Happiness 2019](05-world-happiness/) | Which indicators are associated with happiness? | Correlation, ranking, outliers | Not started |

## Method

Each project is divided into five levels:

1. **Foundations:** loading and inspecting the data.
2. **Cleaning and selection:** missing values, duplicates, filtering and sorting.
3. **Grouping and feature engineering:** aggregation and new columns.
4. **Statistical analysis:** percentiles, correlation and outliers.
5. **Analytical challenges:** comparisons, summary tables and written findings.
